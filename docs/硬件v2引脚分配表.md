## 3. 引脚改动带来的两项固件配置(重要)

1. **控制台改到 USB Serial/JTAG**

   原日志口 43/44 已释放,必须把控制台切到 USB-CDC,否则将看不到日志:

   - `Component config → ESP System Settings → Channel for console output → USB Serial/JTAG`;
   - 或 sdkconfig 中 `CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y`,同时关闭 UART 控制台;
   - `platformio.ini` 的 `monitor_speed` 对 USB-CDC 无效,改为直接 `pio device monitor` 即可。

2. **调试方式改为 USB-JTAG**

   GPIO39~42 被 TFT 占用后,片上 JTAG 不可用;使用 ESP32-S3 内置 USB-JTAG(19/20)进行调试。

## 4. OV2640 电气与接口要点(手册确认)

| 项 | 要求 |
|---|---|
| XVCLK | 6~24MHz,建议 20MHz 起调 |
| PCLK | 摄像头输出,典型 20~36MHz |
| 供电 | 常见模块 3.3V 输入(板载 LDO),逻辑电平 3.3V |
| PWDN | 无内部上下拉,不使用时外部下拉到 GND |
| RESETB | 外部上拉到 DOVDD |
| SCCB | SIOD/SIOC 各 4.7kΩ 上拉 |
| 输出格式 | YUV422 / RGB565 / JPEG(带宽紧张时可用 JPEG) |
| 电源控制 | 用 MOSFET 整体断电,比仅拉 PWDN 更省电 |

## 5. 硬件设计要点

1. **摄像头电源门控**:43 控制 MOSFET,识别完成即断电;PWDN 外部下拉、RESETB 外部上拉;
2. **去耦**:摄像头 VDD 100nF + 10µF;麦克风 VDD 100nF;
3. **走线**:D0~D7 等长;PCLK/XCLK 远离麦克风与模拟信号;
4. **背光**:44 走 PWM 调光;背光属大电流负载,注意 LDO 余量与线宽;
5. **测试点**:XCLK、PCLK、VSYNC、HREF、TFT SCK/MOSI、麦克风 SCK/WS/SD;
6. **机械**:摄像头与麦克风开孔互不遮挡,麦克风远离摄像头排线。

## 7. 电池与电量检测(预留设计)

### 7.1 电源架构建议

```
USB-C ──▶ 充电管理(带 Power Path)──┬──▶ 电池(单节锂电 3.7V, 带保护)
                                    │
                                    └──▶ Buck-Boost / Boost ──▶ 3.3V 主电源轨
                                                                  ├─▶ ESP32-S3
                                                                  ├─▶ 摄像头(经 MOSFET 门控,由 43 控制)
                                                                  ├─▶ TFT 逻辑 + 背光(44 调光)
                                                                  ├─▶ 双麦克风
                                                                  └─▶ 功放(3.3V 或 5V,按模块选)
```

要点:

- 充电 IC 必须带 **Power Path**(边充边用,不让电池承受系统峰值电流),如 BQ2407x 系列;裸 TP4056 不带路径管理,不推荐直接给整机供电;
- 1S 锂电电压 3.0~4.2V,选 **Buck-Boost**(如 TPS63020)直接出 3.3V,效率与续航优于"先升 5V 再降 3.3V";
- 电池选**带保护板**的电芯,或加 DW01+8205 保护;
- 摄像头、背光都是大电流负载,单独走线并留足余量。

### 7.2 电量检测方案对比

| 方案 | 原理 | 占用引脚 | 精度 | 结论 |
|---|---|---|---|---|
| **I2C 电量计(推荐)** | MAX17048 / MAX17043 / BQ27441 等 | **复用现有 I2C(18/21)**,0 额外引脚 | 高(直接给 SoC%) | ✅ 最推荐 |
| ADC 分压采样 | 电池电压经分压进 ADC | 需 ADC 引脚 | 低(需标定,受负载影响) | ❌ 不可行 |
| 充电 IC 状态脚 | CHRG/STDBY 直接驱 LED | 0(直接驱动 LED) | 只能指示充/满 | ✅ 可作辅助 |

**为什么 ADC 方案不可行(手册依据):**

- ESP32-S3 的 ADC2 通道**不能与 Wi-Fi 同时使用**(数据手册明确说明);
- ADC1 通道对应 GPIO1~10,而这些引脚在本项目中已全部分配给摄像头数据线和音频;
- 因此没有空闲的 ADC1 引脚可做电池分压采样。

**I2C 电量计的优势:**

- 与 OV2640 的 SCCB 共用 I2C 总线(GPIO18/21),地址不冲突(OV2640 0x60,MAX17048 0x36);
- 直接输出剩余电量百分比与电压,支持低电量中断;
- 静态电流极低(MAX17048 约 3µA),适合电池常驻场景。

### 7.3 对引脚表的影响

| 功能 | 引脚 | 说明 |
|---|---|---|
| 电量计 I2C | 复用 18(SDA)/21(SCL) | 与摄像头 SCCB 同总线,需确认地址不冲突并加上拉 |
| 电量计型号 | — | 建议 MAX17048(地址 0x36,不与 OV2640 冲突),**采用 I2C 轮询,不占 ALERT 脚** |
| 软关机 / 电源保持 POWER_HOLD | **48(确定)** | 控制负载开关,实现"低电量自动断电";需按键唤醒 |
| 充电状态指示 | 直接由充电 IC 状态脚驱动 LED | 不占 MCU 引脚 |

> 已确定:48 分配给 **POWER_HOLD(软关机)**,电量计用 I2C 轮询读取。

### 7.4 低功耗相关注意

1. 选**低静态电流**的 LDO/Buck-Boost(Iq 越小,待机越省);
2. 电量计静态电流量级 µA,可常开;摄像头、背光、功放按需断电;
3. 设定低电量阈值(如 3.5V / 10%),触发提示并进入深度睡眠或软关机;
4. 软关机后由按键(接 GPIO0 或独立唤醒脚)唤醒,注意深度睡眠唤醒源的引脚限制;
5. 充电时若系统在运行,需确认 Power Path 能同时满足系统峰值电流。
