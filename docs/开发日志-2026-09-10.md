## 一、VAD 功能实现与验收

### 1.1 实现要点

- 输入:16bit PCM 立体声,每块 256 采样帧(16ms);
- 处理:左右声道取较大者 → 转 dB → 与"噪声底 + 门限"比较;
- 双门限迟滞:
  - 起始门限 `floor + VAD_THRESHOLD`(当前 8dB);
  - 维持门限 `floor + VAD_THRESHOLD/2`;
- 自适应噪声底:静音段用 EMA 更新 `noise_db`;
- 状态机:静音/说话两态,起始确认 3 帧、结束确认 18 帧、最短语音 6 帧、最长 30s;
- 事件输出:`VAD_EVENT_START` / `VAD_EVENT_END`。

### 1.2 单句验收结果(通过)

日志 129 块,恰好 **1 次 START + 1 次 END**:

- START:越过门限后第 3 帧触发(≈48ms 起始延迟);
- END:最后一个有声块之后第 18 帧触发(≈288ms),与 `VAD_OFFSET_FRAME=18` 完全一致;
- 误触发 0 次;噪声底在静音段自适应、说话期间冻结,行为符合设计。

## 二、调试过程中发现并修复的问题

| 问题 | 现象 | 根因 | 修复 |
|---|---|---|---|
| 门限未使用 | 低于门限也触发 START | 比较时漏了 `+ VAD_THRESHOLD` | 比较改为 `db >= noise_db + 门限` |
| 噪声底不更新 | `floor` 恒定不变 | EMA 更新分支不可达 | 静音且未超阈值时更新 EMA |
| 测量值被乘系数 | 打印 db 与手算门限对不上 | 把 EMA 系数错乘到测量值上 | 先算原始 dB,EMA 只用于噪声底 |
| START 时帧数为 0 | `frame=0`,最短语音判断失效 | 先清零 `hit_cnt` 再赋值 | 直接赋值 `VAD_ONSET_FRAME` |
| END 提前触发 | 说完话很快就 END | `low_cnt` 未在"有声"时清零,变成累计而非连续 | 有声时 `low_cnt = 0` |
| 日志与源码不一致 | 多次出现"运行结果无法用源码解释" | 修改后未 clean 重建/未重新烧录 | 增加参数打印 + `pio run -t clean` 后重烧 |

**方法论沉淀**:当"运行现象"和"磁盘上的代码"矛盾时,优先怀疑固件是否与源码一致(clean 重建 + 启动参数打印),而不是继续调参。

## 三、标准素材复测与暂停决定

### 3.1 复测发现

- 静音段:SPEAK 占比 3.7%(仅开机瞬间 35 块),优于 10% 目标;
- 语音段:按句子被切成多段(句间停顿超过 288ms 所致),属正常切分,需按策略决定;
- 敲击段/强噪声段:出现长时间停留在 SPEAK(31.8s→47.7s 连续 16s,db 稳定 ~70),判定异常;
- 经确认,部分异常与**原型接线接触不良**有关(松动连线产生宽带突发噪声)。

### 3.2 暂停决定

当前是模块 + 杜邦线原型,数据不可信;在不可靠硬件上调参会"补偿硬件缺陷",换板即失效。

**决定:暂停标准素材复测,等完整硬件电路板(硬件 v2)完成后再定标。**

### 3.3 硬件 v2 需求(已写入文档)

- SD 每根加 100kΩ 下拉;
- 每个麦克风 VDD-GND 就近 100nF 去耦;
- L/R 用焊接跳线明确拉高/拉低;
- SCK/WS/SD 走线短、远离电源,可选 SD 串 22~33Ω;
- 预留 SCK/WS/SD/GND 测试点;
- 3.3V 干净供电并滤波;麦克风开孔声学结构;摄像头/PSRAM 引脚提前规划。
